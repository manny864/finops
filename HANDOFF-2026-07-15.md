## Detalle por tema

### 1. IA — Configuración Global (`/admin/ai-config-global`)
Bug original: "Probar conexión" con DeepSeek fallaba (404 Not Found en logs).
Causa: `@ai-sdk/openai` v3, al invocar el provider directo (`deepseek('...')`),
usa por defecto la **Responses API** (`/responses`), que DeepSeek/Azure no
implementan. Fix: `.chat(...)` para forzar `/chat/completions`.
- Archivos: [`src/modules/core/aiProvider.ts`](src/modules/core/aiProvider.ts)
  (Copilot + evaluador de anomalías), [`src/services/aiService.ts`](src/services/aiService.ts)
  (Reporte Ejecutivo).
- OpenAI real se dejó como está (su Responses API sí es nativa).
- Modelo Anthropic: `claude-3-opus-20240229` estaba **retirado** (2026-01-05 → 404).
  Ahora `claude-sonnet-5`. Labels de UI actualizados en `ai-config-global/page.tsx`
  y `ai-config/page.tsx`.
- Doc: [`docs/ai-provider-chat-api-fix-2026-07-15.md`](docs/ai-provider-chat-api-fix-2026-07-15.md).

### 1b. Copilot FinOps — "El asistente no pudo generar una respuesta"
Bug reportado en prod tras el cambio de modelo a `claude-sonnet-5`: el chat
del Copilot (widget flotante, `GlobalCopilot.tsx`) devolvía el mensaje
genérico de error aunque la config de IA (global y por-tenant) estaba bien.
Logs del VPS confirmaron la causa: `AI_APICallError: "temperature is
deprecated for this model"` — Claude Sonnet 5 (y Opus 4.7+) rechazan con 400
cualquier `temperature` no-default; `claude-3-opus-20240229` (el modelo viejo)
sí lo aceptaba, por eso el bug apareció recién con el cambio de modelo. El 400
llega después de que el stream ya arrancó, así que el cliente solo ve el
stream cortarse sin contenido — de ahí el mensaje genérico.
- Archivo: [`src/app/api/intelligence/copilot/route.ts`](src/app/api/intelligence/copilot/route.ts) —
  se quitó `temperature: 0.2` del `streamText()` (único uso de `temperature`
  en todo el código). El endpoint es provider-agnóstico (google/openai/
  deepseek/azure/anthropic según config del tenant), así que no hay un valor
  universal seguro — sin el parámetro, cada proveedor usa su default.
- Verificado con logs del VPS antes y después del deploy (`docker logs
  finops-finops-app-1 --since Xm | grep -i 'Copilot\|temperature'`).
