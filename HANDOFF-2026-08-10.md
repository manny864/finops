## Implementación realizada

### 1) Directiva de tablas FinOps/CMP (aplicación transversal)

- Filtros estándar por tabla: **Recurso, Región, Tipo, Grupo de recursos**.
- Orden estándar: **A-Z, Z-A, costo mayor→menor, costo menor→mayor**.
- Paginado estándar: **15/30/45/60**.
- Comportamiento UI estándar: **responsive**, **full-width**, columnas **redimensionables**.
- Espaciado uniforme entre bloque de filtros y tabla.

### 2) Monitoreo

- Se eliminó el filtro superior global (`RouteTabsFilter`) en layouts donde estaba presente.
- Se mantuvo el patrón por tabla en:
  - `MonitoringServiceCostBoard`
  - `app-insights/page.tsx`
  - `log-analytics/page.tsx`
- Se normalizó visualización a ancho completo.
- Se corrigió el enrutado para que `/intelligence/monitoreo/alerts` use el board de Monitoreo (no el self-service de otra sección).

### 3) Seguridad

- `SecurityServiceCostBoard` actualizado al patrón completo de tabla FinOps/CMP:
  - filtros base, orden, paginado 15/30/45/60, full-width, resize de columnas.
- `Defender` homologado al mismo estilo y paginado.
- API `GET /api/intelligence/security/service-cost` ampliada con `resources[]` y metadatos estándar:
  - `name`, `region`, `type`, `resourceGroup`, `subscriptionId`, `subscriptionName`, `monthlyCost`.
- Mocks de Seguridad reforzados para demo con filas representativas por familia.

### 4) AI Cost Analytics (Foundry/Azure OpenAI)

- Tendencias de gráficos ajustadas para visualizar progreso MTD desde el día 1.
- Corrección de orden de hooks en `AIAnalyticsDashboard` para evitar runtime error.
- Normalización robusta de fechas en backend para evitar subagregación cuando MySQL devuelve `Date`.
- Protección de “costo real” cuando `CostMeterSnapshots` supera datos incompletos de snapshots AI.
- Versionado de cache para invalidar respuestas stale.

### 5) Cron/Jobs Azure (staging + prod)

- Nuevo endpoint:
  - `GET /api/cron/prewarm-security-finops`
- Objetivo:
  - precalentar `GET /api/intelligence/defender`
  - precalentar `GET /api/intelligence/security/service-cost?family=...`
- Infra:
  - `infra/terraform/environments/staging/staging.tfvars.example`
  - `infra/terraform/environments/prod/terraform.tfvars.example`
- Frecuencia: `*/20 * * * *`.
