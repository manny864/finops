# TTL Enforcement SOP\n\n- **Formato de Fecha**: Se utiliza ISO 8601 (`YYYY-MM-DD`). Cualquier fecha que no cumpla con este formato será evaluada como `NaN` en JS y se omitirá para evitar Falsos Positivos de borrado.\n- **Soporte de Máquinas Virtuales**: El servicio de remediación (`src/services/remediationService.ts`) fue parcheado para soportar el borrado absoluto de Máquinas Virtuales a petición del motor TTL.\n- **UI**: `ExpiredSandboxTable.tsx` dispara un borrado hacia `/api/remediation`. El token y tenant se validan en el backend estrictamente para prevenir accesos cruzados.\n
