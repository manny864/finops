## 3) Migración a Azure Managed Redis (Balanced_B3 + HA)

### Objetivo
Implementar HA mínimo desde el inicio, reemplazando Redis en Container App por Managed Redis privado.

### Qué se cambió
- Módulo `redis` reescrito para usar `azurerm_managed_redis`.
- Configuración:
  - `sku_name = Balanced_B3`
  - `high_availability_enabled = true`
  - `public_network_access = Disabled`
  - `default_database` con protocolo encriptado y access keys habilitadas.
- Se agregó `azurerm_private_endpoint` + `private_dns_zone_group`.
- DNS privado Redis actualizado a:
  - `privatelink.redisenterprise.cache.azure.net`
- En `stamp`:
  - `REDIS_TLS = "true"`
  - `REDIS_HOST/REDIS_PORT` desde outputs del Managed Redis
  - `REDIS_PASSWORD` desde `module.redis.primary_access_key`
- `diagnostics` ahora incluye Redis como target.
- Tipado y wiring de variables actualizados en `dev/prod` para:
  - `redis_sku_name`
  - `redis_high_availability_enabled`
