# Handoff técnico — 2026-08-07

## Estado actual

Se completaron cambios funcionales en Cómputo, Bases de Datos y AI Cost Analytics con foco en datos reales de Azure, cache en Redis y jobs de prewarm.

## Cambios aplicados

1. **Cómputo (UI + API + cache)**
   - Se creó `ComputeWorkloadBoard` y se conectó en:
     - `web-apps-app-services`
     - `functions`
     - `azure-virtual-machines`
     - `virtual-machine-scale-sets`
     - `azure-red-hat-openshift`
   - Nueva API: `GET /api/intelligence/compute/workloads`
   - Cache Redis por familia (`compute:workloads:v1:{tenantId}:{family}`), con `bust=1`.
   - Cron de prewarm: `GET/POST /api/cron/prewarm-compute`.

2. **Bases de Datos (cache + prewarm)**
   - Cache Redis en endpoints:
     - `/api/intelligence/databases/cosmos-diagnostics`
     - `/api/intelligence/databases/sql-diagnostics`
     - `/api/intelligence/databases/postgres-diagnostics`
     - `/api/intelligence/databases/mysql-diagnostics`
     - `/api/intelligence/databases/mongo-diagnostics`
     - `/api/intelligence/databases/redis-diagnostics`
   - Helper compartido en `diagnosticsShared.ts`:
     - `getDiagnosticsCacheKey`
     - `readDiagnosticsCache`
     - `writeDiagnosticsCache`
   - Cron de prewarm: `GET/POST /api/cron/prewarm-databases`.

3. **AI Cost Analytics**
   - Fallback corregido en `src/app/api/intelligence/ai-analytics/route.ts`:
     - Fuente 1: `AICostSnapshots`
     - Fuente 2: `CostMeterSnapshots` (principal fallback)
     - Fuente 3: `CostSnapshots` (legacy fallback)
   - Cache versionado a `ai-analytics:v3:{tenantId}:{days}`.
   - Invalidador de cache en cron sync actualizado para incluir `ai-analytics:v3:*`.

4. **Cron Sync robustecido**
   - Recuperación automática de lock stale (`CRON_SYNC_STALE_MS`, default 20 min).
   - Reinicio forzado con `?force=1` para destrabar corridas colgadas.

## Comandos operativos de validación local

```bash
npm run migrate
curl -H "Authorization: Bearer $CRON_SECRET" "http://localhost:3000/api/cron/sync?force=1"
curl -H "Authorization: Bearer $CRON_SECRET" "http://localhost:3000/api/cron/sync?status=1"
```

Cuando `done=true`, validar AI Analytics y/o usar `bust=1`.
