# SOC 2 Report — Status Overview

> **This document is a status overview of CSCloudSolutions' readiness for SOC 2 Type II certification. It is NOT an audit report issued by an independent third party** — certification has not yet been completed (target: Q3 2027). The formal audit report will be made available under NDA to Enterprise customers once the audit is complete.

## Certification target
SOC 2 Type II, targeting Q3 2027.

## Security controls already in place
- TLS 1.2+ encryption in transit and AES-256 at rest
- RBAC and mandatory MFA via Microsoft Entra ID
- Continuous security monitoring and intrusion detection
- Audit logs retained for 7 years
- Geo-redundant backups, RTO < 4 hours

## Next steps toward certification
- Selection of an accredited external auditor
- Definition of the observation period (Type II requires a minimum 6-month window of operating evidence)
- Formal audit and report issuance
