# Subprocessadores

A CSCloudSolutions utiliza os seguintes processadores terceiros para prestar seus serviços

> Nota: Todos os subprocessadores concordaram com termos de proteção de dados equivalentes ao RGPD. Notificamos os clientes sobre novos subprocessadores e concedemos 30 dias para objeção.

## Residência de Dados
A CSCloudSolutions opera uma única implantação física, hospedada nos Estados Unidos (Azure West US 2). Ainda não oferecemos seleção de residência regional de dados — todos os dados dos clientes são processados e armazenados neste único local, independentemente da região do próprio cliente.

- 🇺🇸 Estados Unidos: Azure West US 2

Planejado: A residência de dados multirregional (UE/EUA/LATAM/APAC) é uma possível melhoria futura, ainda sem cronograma definido. Esta página será atualizada com um prazo definitivo assim que uma implantação multirregional for planejada.

## Detalhes dos Processadores

| Processador | Finalidade | Localizações |
|---|---|---|
| Microsoft Azure | Computação, armazenamento, rede e processamento de dados na nuvem | Estados Unidos |
| Host de Banco de Dados MySQL | Hospedagem de banco de dados relacional e backups | Estados Unidos |
| Paddle | Processamento de pagamentos, faturamento e gestão de assinaturas | Estados Unidos / Reino Unido |
| WorkOS | Autenticação SSO/SAML 2.0 e gestão de identidade | Estados Unidos |
| Google Gemini AI | Inferência de LLM para recomendações (opcional, com chave própria suportada) | Estados Unidos |
| Microsoft Graph | Integração de e-mail e calendário para notificações | Estados Unidos |
| Cloudflare | CDN, WAF de borda e proteção DDoS | Rede global de borda, origem nos Estados Unidos |

Proteção de dados: este processador se comprometeu a tratar dados em conformidade com o RGPD e padrões equivalentes.
DPA disponível: sim. Cláusulas Contratuais Padrão incluídas em seus acordos de tratamento de dados.

## Política de Alteração de Subprocessadores
Podemos alterar ou adicionar subprocessadores a qualquer momento. Você será notificado com antecedência por e-mail (pelo menos 30 dias antes) e terá o direito de:
- Revisar as práticas de segurança e privacidade do novo processador
- Se opor à adição dentro de 30 dias
- Cancelar sua assinatura caso adicionemos um processador que você não possa aceitar
