# Subencargados

CSCloudSolutions utiliza los siguientes encargados externos para prestar sus servicios

> Nota: Todos los subencargados han aceptado términos de protección de datos equivalentes al RGPD. Notificamos a los clientes sobre nuevos subencargados y otorgamos 30 días para objetar.

## Residencia de los Datos
CSCloudSolutions actualmente opera un único despliegue físico, alojado en Brasil (Latinoamérica). Todavía no ofrecemos selección de residencia regional de datos: todos los datos de los clientes se procesan y almacenan en esta única ubicación, sin importar la región propia del cliente.

- 🌎 Latinoamérica (Brasil): Azure Brazil South

Planificado: La residencia de datos multirregión (UE/EE. UU./LATAM/APAC) es una posible mejora futura, aún sin cronograma definido. Esta página se actualizará con un plazo concreto cuando se planifique un despliegue multirregión.

## Detalle de los Encargados

| Encargado | Finalidad | Ubicaciones |
|---|---|---|
| Microsoft Azure | Cómputo, almacenamiento, redes y procesamiento de datos en la nube | Brasil (Latinoamérica) |
| Servidor de Base de Datos MySQL | Alojamiento de base de datos relacional y copias de seguridad | Brasil (Latinoamérica) |
| Paddle | Procesamiento de pagos, facturación y gestión de suscripciones | Estados Unidos / Reino Unido |
| WorkOS | Autenticación SSO/SAML 2.0 y gestión de identidad | Estados Unidos |
| Google Gemini AI | Inferencia de modelos de lenguaje para recomendaciones (opcional, con clave propia soportada) | Estados Unidos |
| Microsoft Graph | Integración de correo y calendario para notificaciones | Estados Unidos |

Protección de datos: este encargado se ha comprometido a procesar datos conforme al RGPD y estándares equivalentes.
DPA disponible: sí. Sus acuerdos de tratamiento de datos incluyen Cláusulas Contractuales Tipo.

## Política de Cambio de Subencargados
Podemos cambiar o agregar subencargados en cualquier momento. Se notificará con anticipación por correo electrónico (al menos 30 días antes), y el cliente tiene derecho a:
- Revisar las prácticas de seguridad y privacidad del nuevo encargado
- Objetar la incorporación dentro de los 30 días
- Cancelar la suscripción si se agrega un encargado que no se pueda aceptar
